# 9. よくある質問・困ったとき

[目次に戻る](README.md)

## 起動・インストール

**Q. 「Windows によって PC が保護されました」と表示されて起動できません。**
「詳細情報」を押し、表示された「実行」を押してください。

**Q. `NovelAILocalGUI.exe` だけをコピーしたら起動しなくなりました。**
フォルダの中の `_internal` なども起動に必要です。フォルダごと使ってください。

## 生成

**Q. 生成するとエラーになります。**
エラーの内容によって原因が異なります。

- API キーに関するエラー: API キーが間違っているか、NovelAI で新しいトークンを発行して古いものが使えなくなっています。設定画面で API キーを設定し直してください。
- Anlas が足りないというエラー: Anlas の残高が足りません。見積りを確認し、サイズやステップ、枚数を減らしてください。
- 送信が多すぎるというエラー: 少し時間をおいてから、もう一度試してください。

**Q. 見積りと実際の消費 Anlas が違います。**
見積りは NovelAI 公式サイトと同じ計算方法に合わせていますが、目安です。Opus の V5 生成の残量や、NovelAI 側の変更によって異なる場合があります。

**Q. Precise Reference や Vibe Transfer が選べません。**
使える方式はモデルによって違います。Precise Reference は V4.5、Vibe Transfer は V3 / V4 / V4.5 で使えます([参照画像](04-reference-img2img.md)を参照)。

**Q. 同じシードで生成し直したいのに、シードが入力できません。**
「ランダム固定」がオンになっています。オフにしてください。

## 保存

**Q. 画像がどこに保存されたか分かりません。**
生成の後、画面の一番下に保存先が表示されます。保存先は設定画面の「保存」で確認・変更できます。「日付ごとのフォルダに分けて保存する」がオンの場合は、保存先の中の日付のフォルダに保存されます。

## アップデート・アンインストール

**Q. アップデートの方法は?**
[体験版と製品版・アップデート](08-editions-update.md)を参照してください。

**Q. アンインストールするには?**
アプリのフォルダを削除してください。API キーも消したい場合は、削除する前に設定画面の「API キー」の「削除」を押してください。

## お問い合わせ

解決しない場合は、次のどちらかでご連絡ください。

- BOOTH のショップのメッセージ機能([販売ページ](https://zero0milk.booth.pm/items/8889836)のショップから)
- [Issues](../../../issues)(誰でも閲覧できるため、API キーや個人を特定できる情報は書き込まないでください)

不具合の報告には、アプリのバージョン(設定画面の「アプリ情報」)と、起きたこと・再現手順を添えてください。
