# 8. 体験版と製品版・アップデート

[目次に戻る](README.md)

## 体験版と製品版の違い

体験版でも、機能はすべて使えます。違いは次の 3 点です。

| | 体験版 | 製品版 |
|---|---|---|
| 生成・後処理した画像 | 透かしが入ります | 透かしなし |
| キュー | 同時に 5 件まで | 上限なし |
| Anlas を消費する送信 | 送信前に確認が表示されます | 確認なし(見積りは常に表示) |

体験版の画面上部には「体験版」と「製品版を入手」が表示されます。「製品版を入手」を押すと BOOTH の販売ページが開きます。
透かしが入った画像にも生成設定は埋め込まれているので、ドラッグ&ドロップで設定を読み込めます。

## 体験版から製品版に切り替える

1. [BOOTH の販売ページ](https://zero0milk.booth.pm/items/8889836)で製品版を購入し、購入履歴から製品版の zip をダウンロードします。
2. 展開して、製品版の `NovelAILocalGUI.exe` を起動します。

API キー、テーマ、保存先などの設定は Windows に保存されているため、そのまま引き継がれます。体験版のフォルダは削除してかまいません。

## アップデート

新しいバージョンが公開されると、起動時に通知が表示されます。「はい」を押すと BOOTH の販売ページが開きます。

1. BOOTH の購入履歴から、新しいバージョンの zip をダウンロードします(アップデートは無料です)。
2. 古いフォルダを削除し、新しい zip を展開します。
3. 新しい `NovelAILocalGUI.exe` を起動します。

設定はそのまま引き継がれます。ショートカットを作っている場合は、新しい `NovelAILocalGUI.exe` のショートカットを作り直してください。
